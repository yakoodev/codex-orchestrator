# OSS процесс

## Лицензирование и релизы
- License: Apache-2.0
- Versioning: SemVer
- Release artifacts: Git tags + changelog

## Contribution policy
- Contract-first изменения.
- Документация и контракты обновляются в одном PR с логикой.
- Security-sensitive зоны требуют отдельного review.

## CI minimum gates
- lint
- typecheck
- unit
- contract checks

## PR шаблоны и issue шаблоны
- Используются файлы из `.github/`.
